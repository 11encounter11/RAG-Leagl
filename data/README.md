# `data/` 说明

三个东西：`raw/`（语料，**不入库**）、`corpus_manifest.json`（语料清单，**运行时依赖**）、`eval/`（评测集与基线）。

## `raw/` —— 法规原文

被 `.gitignore` 忽略，所以 **clone 下来是空的**，需要你自行获取。

- **来源**：国家法律法规数据库 `https://flk.npc.gov.cn/` —— 站内搜索 → 勾选条目 → 「批量下载文件」，选 `.docx`（官方排版正文）。
- **不要用 AI 生成的文本当底本**。理由不是质量问题，是本项目的前提：如果底本本身来源不可核验，"每条依据都能点开核验"这个承诺从根上不成立。
- **命名规则**：`<法名>_<公布或修正日期YYYYMMDD>.docx`。**日期后缀必须保留**——同一部法的多个版本靠它区分，而 `law_versions` 是按文件名去清单里匹配版本的；名字错了 → 拿不到 `version_id` → 时效过滤静默失效（服务照常跑，不报错）。
- 该库只收宪法 / 法律 / 行政法规 / 监察法规 / 地方性法规 / 司法解释，**不收部门规章**（《工资支付暂行规定》这类要去人社部官网取）。
- 版权依据：《著作权法》第五条 —— 法律法规及国家机关具有立法、行政、司法性质的文件不适用著作权法。

当前清单是 9 份 docx = 7 部法 / 703 个条文片段，其中两组**版本对**（同一部法的现行版 + 旧版），用来验证时效过滤真的生效：

```
中华人民共和国劳动法_20181229.docx        现行有效  ←┐ 一组版本对
中华人民共和国劳动法_20090827.docx        已修订    ←┘
中华人民共和国社会保险法_20181229.docx    现行有效  ←┐ 另一组
中华人民共和国社会保险法_20101028.docx    已修订    ←┘
中华人民共和国劳动合同法_20121228.docx    现行有效
中华人民共和国劳动争议调解仲裁法_20071229.docx
工伤保险条例_20101220.docx
职工带薪年休假条例_20071214.docx
保障农民工工资支付条例_20191230.docx
```

下载完先核对：`python scripts/verify_corpus.py`。

## `corpus_manifest.json` —— 语料清单（运行时读它）

**这不是文档，是配置。** `app/core/law_versions.py` 在运行时读它，用它决定每条 chunk 的 `version_id` 与时效状态；`scripts/seed_law_versions.py` 把它灌进 `law_versions` 表。删掉或改错，时效能力会静默失效。

每份文件记录：`law_name` / `version_label` / `publish_date` / `effective_date` / `validity_status` / `version_group` / `region_code` / `doc_type` / SHA-256。校验和的**单一事实来源就是这个 JSON**，别在别处抄一份，两处各写必然漂移。

自己加语料时：把文件放进 `raw/` → 在 manifest 里补一条（含哈希，可跑 `verify_corpus.py --update` 自动生成）→ `seed_law_versions.py` → 重新索引。

## `eval/` —— 评测集与基线

| 文件 | 是什么 |
|---|---|
| `legal_qa_eval.jsonl` | 52 道人工标注题（36 道可判定 + 16 道超纲），每题标「必须命中哪部法的哪一条」 |
| `baseline.json` | `direct` 路径基线（重排开）：Recall@5 0.9167 / 完整召回 0.8056 / MRR 0.7315 / NDCG@5 0.7612 / 未命中 3 条 |
| `baseline-agentic.json` | `agentic` 生产路径基线：端到端 Recall@5 0.8611 / 放行子集 0.9118 / 库内误拒 2/36 / 超纲拒答 16/16 |
| `README.md` | 指标口径、字段含义、匹配规则（为什么必须按「法名 + 条文号」而不是只比条文号） |
| `reports/` | 运行产物，已 gitignore |

跑法见 `scripts/README.md` 里的 `run_eval.py` 一节。一句话先提醒：**这两份基线不能互相减数字**，`direct` 不经过改写、重试与反思，`agentic` 一旦拒答就把候选清空、该题记 0，两边量的不是同一件事。

这套评测集是人工标注的，属于**源代码级资产**而不是可再生数据，所以签入版本库。标准答案必须真实存在于语料里，`--check` 会强制校验——按记忆标注是最容易出错也最难发现的：指标会虚低，而原因看起来像"检索不行"。
