# 已废弃脚本

这里的代码**不要运行**，保留只为留存记录与事后对照。

| 文件 | 废弃日期 | 原因 |
|---|---|---|
| `prepare_data.py` | 2026-10-14 | 用 AI 生成法律文本填充 `data/raw/`。语料已改为国家法律法规数据库的官方文本，本脚本的输出不再作为任何用途的底本 |

## 背景

2026-10-14 之前，`data/raw/` 里的语料由 `prepare_data.py` 用 AI 生成的文本生成
（内嵌 4 部法的全文）。后来核实：它生成的《中华人民共和国劳动法》与官方文本
**条文号完全一致、内容仅 5 条不同**（恰为 2018 年修正处），质量并不差。

但它仍然被弃用，原因有两条：

1. **来源不可核验** —— 本项目的核心承诺是"每条依据都能点开核验"。底本若是模型生成的，
   这个承诺从根上就不成立：无法向用户证明这段文字是真实的法条。
2. **结构是坏的** —— AI 文本把章节标题粘进了正文（如第十五条结尾直接跟着
   "第三章劳动合同和集体合同"），而官方 docx 里章节是独立段落，这会让章节路径抽取出错。

现在的语料获取流程见 `docs/08-语料清单.md`。
